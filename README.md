# 🧪 demopage · Prototipo del Menú Digital

Primera versión del **menú digital para restaurante**: un prototipo funcional con API y frontend en el mismo repositorio. Aquí nació la idea que luego se dividió en frontend y API independientes.

## ✅ Estado

**Prototipo inicial** — conservado como referencia histórica. La versión en producción vive en:

- **Frontend:** [cristianagutierrezalc/pagdemodev](https://github.com/cristianagutierrezalc/pagdemodev)
- **API:** [cristianagutierrezalc/backend-fuego-carbon](https://github.com/cristianagutierrezalc/backend-fuego-carbon)

## 🧱 Estructura

```
demopage/
├── index.html   # Frontend del prototipo
├── main.py      # API básica (FastAPI)
└── img.png      # Captura
```
